 🌍 Overview
This project automates the process of reading big documents using RAG (Retrieval-Augmented Generation).  
It breaks down the file into chunks, creates embeddings, stores them in Supabase Vector DB,
and retrieves the most relevant information whenever you ask a question.

---

## ⚡ Features
- Reads large PDF files instantly  
- Understands any topic from the document  
- Gives fast, context-aware answers  
- Uses **OpenAI embeddings** for accuracy  
- Fully automated with **n8n** and **Supabase**

---

## 💡 Use Cases
- Quickly explore chapters from long books  
- Analyze large research papers or reports  
- Extract insights from government documents  
- Build document-based chatbots or assistants  
- Save hours of manual searching and reading
